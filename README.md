## ⚡ Hosted Utilities

*   👁️ **[Eye Rest Monitor](https://7-tarun.github.io/Vibe-Coding/Eye-Break/)**  
    Protect your vision effortlessly. A customizable 20-20-20 rule timer with background execution and sound notifications to eliminate digital eye strain.

    Track your fitness metrics instantly. A fast, demographic-aware dashboard featuring BMI and strict U.S. Navy standard Body Fat calculators.
